# src/mobile — интерфейс для телефонов

Всё, что относится только к телефонам, лежит здесь. Ядро плеера (Rust) и
основной интерфейс (`app.js`, `app.css`) общие с ПК: этот слой только
перестраивает их под палец и экран телефона.

| Файл | Что делает |
|---|---|
| `detect.js` | В `<head>` до первой отрисовки ставит `html[data-mobile]` (iOS/Android) и `data-orient="port"/"land"`. |
| `mobile.css` | Внешний вид. Каждое правило под `html[data-mobile]`, поэтому ПК-версию не задевает. |
| `mobile.js` | Поведение: вкладки «Плеер · Текст · Очередь» в полноэкранном плеере, свайп вниз — закрыть плеер, свайп по обложке — следующий/предыдущий трек, свайп вверх по мини-плееру — открыть плеер. |

Настроено под iPhone 16 (393×852 pt, Dynamic Island, отступы 59 pt сверху и 34 pt снизу).

## Проверка в браузере

`npm run web`, затем откройте `http://localhost:1420/?mobile=1` и включите в
инструментах разработчика размер телефона. `?mobile=0` возвращает ПК-вид.

## Сборка для iPhone

Каждый push в `main` запускает `.github/workflows/ios.yml`. Готовый
`Meowave.ipa` лежит в артефактах запуска (Actions → iOS Build → Artifacts).
