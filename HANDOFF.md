## Правила для каждого агента (обязательно)

1. **В начале сессии** прочитай этот файл целиком, потом `AGENTS.md` и `brain/Home.md`. Сразу добавь запись в «Журнал сессий» (в самом низу): дата, кто ты (модель), что собираешься делать.
2. **Во время работы** после каждого заметного шага (коммит, пуш, найденная причина бага, принятое решение) обновляй разделы «Сейчас в работе» и «Очередь задач». Пиши так, чтобы другой агент мог продолжить с середины без тебя.
3. **Пушь часто**, хотя бы в ветку `wip/<тема>`. Песочница агента может пропасть в любой момент вместе со всем незапушенным: в раунде 10 агента прервали посреди работы, и звуковой движок уцелел только потому, что был в `wip/round10`.
4. **Перед тем как закончить**, или если тебя могут прервать, допиши в журнал сессий: что сделано, что не доделано, с чего начать следующему. Обнови «Состояние», «Сейчас в работе» и «Очередь задач». Коммить этот файл вместе с кодом.
5. **Ничего не стирай**: журнал сессий только дописывается. Выполненный пункт очереди отмечай `[x]` с датой и коммитом, а не удаляй.
6. **Никаких секретов** в репозитории, в `brain/`, в коммитах и в ответах владельцу: токены, пароли, ключи, Client Secret. Писать можно только *где* лежит секрет.
7. Пиши по-русски, коротко и по делу: файлы, функции, коммиты, команды. Владелец пишет коротко и с опечатками — сохраняй его запрос дословно в `brain/Log/Requests.md`.
8. Порядок раунда: запрос → `brain/Log/Requests.md` → работа → проверки (`.agents/skills/meowave-rust-check`, `meowave-ui-verify`) → `brain/` и README → коммит с явными путями → пуш в `beta-redesign` и `main` → CI зелёный → короткий отчёт владельцу (`.agents/skills/meowave-ship`).

## Быстрый старт в новой песочнице

Песочница бывает пустой: в сессии 2026-11-05 вечером `/data` был пуст, всё пришлось ставить заново (≈5 минут).

```bash
# 1. Токен владельца (fine-grained, репозиторий kotar1223/meowave-beta, есть право Workflows).
#    Лежит ВНЕ репозитория: /data/.secrets/github_token (права 600). Владелец просил его не удалять — отзовёт сам.
#    Если файла нет (новая песочница) — токен есть в переписке с владельцем; положи его туда же, в репозиторий — никогда.
git config --global credential.https://github.com.helper '!f() { test "$1" = get && echo username=x-access-token && echo "password=$(cat /data/.secrets/github_token)"; }; f'
git config --global user.name "Notion AI"; git config --global user.email "ai@notion.so"
git clone https://github.com/kotar1223/meowave-beta.git /data/meowave-beta

# 2. Rust и системные библиотеки (Amazon Linux / Fedora; для Ubuntu см. .agents/skills/meowave-rust-check)
sudo dnf install -y webkit2gtk4.1-devel gtk3-devel libsoup3-devel javascriptcoregtk4.1-devel openssl-devel librsvg2-devel alsa-lib-devel dbus-devel
export RUSTUP_HOME=/data/.rust/rustup CARGO_HOME=/data/.rust/cargo PATH=/data/.rust/cargo/bin:$PATH CARGO_TARGET_DIR=/data/.rust/target
curl -sSf https://sh.rustup.rs | sh -s -- -y --profile minimal --no-modify-path && rustup component add clippy

# 3. Проверки, как в CI
cd /data/meowave-beta/src-tauri && cargo clippy --all-targets -- -D warnings && cargo test
cd /data/meowave-beta && for f in src/*.js; do node --check "$f"; done && node tests/run-e2e.mjs
```

- **Тесты звукового движка** (выключены по умолчанию, нужен ffmpeg): создай в папке файлы **длиннее 2 минут** (тест перематывает на 100 с) — `yt140.m4a` (фрагментированный AAC: `-movflags +dash+global_sidx -frag_duration 10000000`), `t_end.m4a`, `t.mp3`, `t48.flac` (48 кГц), `t.ogg` (Vorbis), `yt251.webm` (Opus) — и запусти `MW_ITEST_DIR=<папка> cargo test --lib itest -- --ignored --nocapture --test-threads 1`.
- **Скриншоты интерфейса**: `cd src && python3 -m http.server 8777` + Playwright с системным Chromium (`/usr/local/bin/chromium`); подробности в `.agents/skills/meowave-ui-verify`.
- **Долгие команды** (cargo на 2 ядрах — 3–6 минут) запускай отдельно: `setsid -f bash script.sh > log 2>&1 < /dev/null`, потом читай лог. Не делай `pkill -f <шаблон>`, который совпадает с текстом твоей же команды — убьёшь сам себя.
- **Сеть песочницы**: YouTube отвечает ей «подтвердите, что вы не бот», поэтому живые потоки и видео YouTube отсюда не проверить — только у владельца.
