# Как запустить

## Что нужно (Windows)
- **Node.js** LTS **20.19+ или 22.12+** (интерфейс с шага 2 стека собирает Vite 8): https://nodejs.org. Проверить: `node -v`
- **Rust** stable (MSVC) через https://rustup.rs
- **Visual Studio Build Tools** с компонентом «Разработка классических приложений на C++»: без него Rust не слинкует приложение
- **WebView2**: в Windows 11 уже установлен
- **Git**

## Забрать бету и запустить
```powershell
cd C:\meowave-beta
git fetch origin
git checkout beta-redesign
git pull
npm run dev
```
- `npm run dev` сам ставит изменившиеся зависимости (`npm install --no-save`, если поменялся `package-lock.json`), собирает интерфейс (`src/` → `dist/`) и запускает окно. Отдельный `npm install` нужен, только если этот шаг не прошёл (нет сети).
- Обычно обновляться не нужно и так: кнопка в «Настройки → О приложении» делает `git pull`, собирает интерфейс, и окно перезапускается само.
- Перед запуском закрой установленный Meowave, чтобы не перепутать окна.
- Окно показывает встроенный в программу `dist/`: правка в `src/` доходит до него через пересборку, которую `npm run dev` делает сам (окно перезапустится). `Ctrl+F5` тут не поможет и не нужен.
- Первая сборка Rust идёт несколько минут, следующие быстрее.
- Как понять, что запущена новая версия (раунд 6): в Настройки → **Аккаунты** — монохромный список площадок с кнопками-контурами «Войти» (без белых плашек), у Deezer новый знак-сердце; в Настройки → Вид у «Иконки приложения» нет неоновых вариантов, а «Свечение» называется «Свечение волны»; углы у настроек заметно квадратнее; в Настройки → Сеть → «Проверка YouTube Music» у каждого клиента есть «окно 1 МБ» и «запрос «до конца»»; мини-плеер (`Ctrl+M`) перетаскивается за карточку. Новых зависимостей Rust нет, но добавились файлы `browser.rs` и `fsguard.rs` — первая сборка пересоберёт крейт.
- Ярлык на рабочем столе и в «Пуске» запускает **установленную** версию, она сама не обновляется. Бету открывает только `npm run dev` (или новый установщик после `npm run build`).

## Сборка установщика
```powershell
npm run build
```
Скрипт скачивает ffmpeg (`scripts/fetch-ffmpeg.mjs`) и вызывает `tauri build`. Установщик появится в `src-tauri\target\release\bundle\`.
Новая иконка на рабочем столе и в «Пуске» появится только после установки новой сборки (см. [[Features/App icon]]).

## Проверки
| Команда | Что делает |
|---|---|
| `npm run check:js` | проверка синтаксиса `src/app.js`, `src/messenger.js` и типов `src/ts` |
| `npm run typecheck` | проверка типов модулей на TypeScript (`src/ts`) |
| `npm run web:build` | сборка интерфейса `src/` → `dist/` (Vite) |
| `npm run web` | Vite dev-сервер http://127.0.0.1:1420 — интерфейс в браузере без Tauri |
| `npm run test:e2e` | e2e-тесты `tests/run-e2e.mjs`: инварианты HTML/CSS/JS, анимации, reduced motion, граничные случаи |
| `npm run check` | сборка интерфейса, затем `cargo clippy -D warnings` и `cargo test` для Rust |

Ожидаемый результат e2e: 312 тестов прошли, 5 пропущены (на Node без запуска `.ts` — старше 22.18 / 23.6 — пропущен ещё F26-06). Пропуски не ошибки: это проверки, которые статикой не сделать (например, движение волны во время игры).

## Частые ошибки
- **После `git pull` ничего не изменилось.** Обычно локальная ветка `beta-redesign` не связана с GitHub: например, её создали из патча командами `git checkout -b` и `git am`. Тогда `git pull` ничего не скачивает. Ещё одна причина — локальные правки в папке. Решение:
  ```powershell
  cd C:\meowave-beta
  git fetch origin
  git stash -u
  git checkout -f -B beta-redesign origin/beta-redesign
  git log --oneline -1
  ```
  `git stash -u` сохраняет локальные правки, если они были. Последняя строка должна показать последний коммит ветки с GitHub.
  Частые причины, почему `git pull` не помог:
  - папка на ветке `main`: в бета-репозитории `main` пока старая, всё новое — в `beta-redesign` (проверка: `git branch --show-current`);
  - `git pull` остановился с `error: Your local changes … would be overwritten` — например, сборка поменяла `src-tauri/Cargo.lock`; ошибку легко не заметить, и запускается старый код;
  - команды выполнены не в той папке (например, в `C:\meowave` вместо `C:\meowave-beta`).
- **`'tauri' is not recognized`**: не выполнен `npm install`. CLI Tauri ставится из пакета `@tauri-apps/cli`. С шага 2 стека `npm run dev` ставит зависимости сам; если ошибка всё же есть — выполни `npm install` и посмотри, что он пишет.
- **`Meowave: для сборки интерфейса нужен Node.js 20.19+ или 22.12+`**: старый Node. Поставь LTS с nodejs.org, открой новый терминал, `npm run dev`.
- **В окне страница «Интерфейс не собран»**: сборка интерфейса не прошла (причина — внизу страницы). Закрой Meowave и запусти `npm run dev` — в терминале будет видно, что не так (чаще всего нет сети для `npm install` или старый Node).
- **`could not find Cargo.toml`**: `cargo run` в корне не нужен. Rust-проект лежит в `src-tauri`, его собирает `npm run dev`.
- **`cargo` не найден**: поставь Rust через rustup и открой новый терминал.
- **Ошибка компиляции Rust**: пришли полный текст ошибки. В песочнице агента Rust проверяется под Linux (`cargo clippy`, `cargo test`), а сборка под Windows — только у тебя (см. [[Known issues]]).
- **Discord не показывает статус**: нужен Application ID, см. [[Features/Discord RPC]].

## Git-процесс
- `origin` — `kotar1223/meowave-beta` (приватный), `upstream` — `kotar1223/meowave` (публичный).
- Работа идёт в ветке `beta-redesign`, изменения попадают в `main` бета-репозитория через PR #1.
- Когда бета проверена: слить PR в `main`, затем перенести в публичный репозиторий (`git push upstream main` или отдельный PR).
