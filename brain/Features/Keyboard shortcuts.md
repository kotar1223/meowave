# Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | пауза / play |
| `Shift+→` / `Shift+←` | следующий / предыдущий трек |
| `Esc` | закрыть верхний слой: поповер → список сервисов → настройки плеера → эквалайзер → настройки; затем полноэкранный плеер |
| `L` | в полноэкранном плеере: текст ↔ сцена |
| `Q` | в полноэкранном плеере: очередь |
| `E` | эквалайзер |
| `[` / `]` (`х` / `ъ`) | смещение текста −0,5 / +0,5 с |
| `{` или `Alt+0` | сбросить смещение текста |
| `F11` | полноэкранный режим окна |
| `Enter` на обложке | переключить текст |
| стрелки / `Home` на полосе EQ | ±0,5 dB / сброс полосы |
