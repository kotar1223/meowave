# Встроенный звуковой движок (раунд 10)

Запрос владельца: «эквалайзером и звуком займись, и тщательно» — после жалоб на помехи, обрывы и на то, что на Linux эквалайзер и скорость не применялись.

## Что это
Звук на десктопе декодирует, обрабатывает и выводит Rust, а не WebView. Включён по умолчанию; переключатель — «Настройки → Звук → Качество → Звуковой движок: Встроенный / WebView». Там же видно устройство вывода, частоту и число каналов.

## Как устроен
- `source.rs` — поток из локального прокси (`stream.rs` уже умеет все сервисы, окна googlevideo, HLS, расшифровку) читается наперёд в разреженный буфер страницами; перемотка за скачанное перезапускает загрузку с нового места, дыры дозаполняются; память ограничена.
- `mp4.rs` — `sidx` фрагментированного MP4 (YouTube, CMAF SoundCloud): старт без ожидания всего файла и перемотка сразу в нужный фрагмент.
- `decode.rs` — symphonia: MP3, AAC-LC, FLAC, ALAC, Vorbis, WAV/AIFF. Opus и HE-AAC — нет: такой трек автоматически играет WebView.
- `resample.rs` — к частоте устройства и под скорость 0,5–1,5× (тон меняется вместе со скоростью, как в WebView).
- `dsp.rs` — preamp → 10 полос → 3D или обход + реверб (свёртка) → громкость → выравнивание громкости → затухание → усиление → лимитер с заглядыванием вперёд; спектр для визуала. Плоский эквалайзер на единичном усилении пропускает сэмплы без изменений.
- `output.rs` — cpal (WASAPI, CoreAudio, ALSA), кольцо без блокировок `rtrb`: обратный вызов устройства только копирует, поэтому не опаздывает; пауза — короткий спад громкости без щелчка; TPDF-дизеринг для целых форматов; смена устройства на лету.
- `engine.rs` — поток рендера, поток статуса (позиция по меткам кольца — точная при любой скорости), порядок команд (номер операции отбрасывает устаревшие вызовы IPC).
- `src/naudio.js` — объект с поверхностью `<audio>` (события, `currentTime`, `buffered`, `paused`…), поэтому `app.js` не раздвоился.

## Проверки (раунд 10)
- 10 интеграционных тестов (`engine/itest.rs`, `--ignored`): сервер с Range → весь тракт → имитация устройства в реальном времени. Совпадение с ffmpeg 95–135 дБ; позиция ±30 мс; перемотка вперёд, назад, пауза; FLAC 48 кГц на 44,1 кГц; Vorbis на 48 кГц; окна CDN по 64 КБ; скорость 1,25×; Opus честно отдаётся WebView.
- Юнит-тесты фильтров, ресемплера, MP4, источника, преобразования форматов.
- Не проверено: настоящие звуковые карты, Bluetooth, переключение устройств — у владельца.
