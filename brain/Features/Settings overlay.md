# Настройки поверх приложения

Запрос: «вкладку настроек тоже переработай или можно как наложение её сделать».
- Настройки открываются окном поверх приложения, как в Liner. Слева поиск и разделы («Аккаунты», «Профиль», «Звук», «Вид», «Фонотека», «Приватность», «Сеть», «О приложении»), справа содержимое.
- Поиск подсвечивает совпадения (`data-hit`), Enter прокручивает к первому, Esc очищает поле, повторный Esc закрывает окно.
- Закрытие: крестик, Esc, клик по фону.
- Заголовок раздела, повторяющий название вкладки, скрывается (`setovTitle()`).
- Код: `setovInit()`, `openSettings(tab)`, `closeSettings()`, `setovSearch()`, `settingsIsOpen()`; CSS `.setov`, `#v-settings.setov-box`. Элемент `#v-settings` остаётся в DOM: его требуют тесты.
