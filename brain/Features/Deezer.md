# Deezer

Запрос: «надо как-то сделать Deezer».
- Сервис в списке сервисов: поиск, чарты, плейлисты, альбомы, артисты, радио артиста (`dz.rs`, публичный API без ключей).
- Звук: Deezer без входа отдаёт только 30-секундные превью. Поэтому полный трек ищется строгим подбором (`matching.rs`) на YouTube Music, Яндексе или SoundCloud; если совпадения нет — играет превью, и плеер об этом говорит.
- Deezer — запасной источник профиля артиста и одна из вкладок шторки подборок.
