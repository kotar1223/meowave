# Импорт плейлистов

**Раунд 1** (запрос «сделать нормальный импорт с красивым дизайном»):
- сервис определяется по ссылке сразу, вставленная ссылка проверяется без лишнего клика;
- показываются первые треки с обложками;
- можно задать своё название плейлиста;
- ошибки видны прямо в окне.

**Раунд 5** (запрос «подключать свои аккаунты… оттуда импортировать треки»):
- Настройки → Аккаунты → «Импорт» на карточке: любимые треки и плейлисты подключённого аккаунта YouTube Music, SoundCloud или Deezer; Яндекс и Spotify — как раньше. Подробнее — [[Features/Accounts]].
- Повторный импорт дописывает тот же плейлист (метка `src` = `<сервис>:<id>`), а не создаёт копию; удалённые на площадке треки при этом остаются. Любимые треки второй раз в избранное не попадают.
- Треки из аккаунта приходят готовыми, без поиска по одному: до 5000 за раз (для поиска по названию лимит прежний — 200).
- Импорт по ссылке остался: «Импорт по ссылке» внизу вкладки «Аккаунты».

**Раунд 7** (запрос «сделай нормальную иконку импорта»): плитка «Импорт» в «Медиа» — близнец плитки «Новый плейлист»: тот же спокойный квадрат, знак `download` по центру вместо облака.
