# Конструктор интерфейса

Запрос раунда 7: «сделай более детальную кастомизацию, чтобы каждый элемент можно было менять».

Где: **Настройки → Вид → «Конструктор интерфейса»**. Всё применяется сразу, любой пункт сбрасывается отдельно (круглая стрелка в строке), раздел — «Сбросить раздел», всё — «Сбросить всё».

## Разделы (13, 56 пунктов)
- **Основа** — фон приложения, основной и второстепенный текст, линии и рамки, размер текста, масштаб интерфейса (зум окна, только в приложении).
- **Панели** — цвет, непрозрачность, поле поиска, скругление, тени.
- **Боковое меню** — фон, выбранный пункт, иконки и подписи, подписи под иконками, логотип.
- **Плеер** — фон, скругление, полоса прогресса, волна на полосе, кнопка воспроизведения, иконки и время, скругление обложки.
- **Обложки** — скругление, тени, подъём при наведении.
- **Кнопки и переключатели** — форма кнопок (круглые / скруглённые / строгие), главные кнопки, выбранный вариант, включённые переключатели.
- **Списки треков** — плотность, подсветка при наведении, разделители.
- **Главная и частицы** — размер и цвет заголовка, подзаголовок, панель «Подборки», цвет и яркость частиц.
- **Полноэкранный плеер** — скругление обложки, текущая и остальные строки песни.
- **Чаты** — мои и входящие сообщения, фон переписки, скругление сообщений, размер текста.
- **Меню, окна, уведомления** — контекстные меню, окна и настройки, скругление окон, уведомления, затемнение под окнами.
- **Полосы прокрутки** — ширина, цвет.
- **Заголовок окна** — фон, название и значок (только окно приложения на компьютере).

Цвета хранятся **отдельно для тёмной и светлой темы** (подпись «Цвета сохраняются для тёмной темы» показывает, какую правите); размеры, формы и видимость — общие.

## Готовые стили
Стандарт, Компактный, Мягкий, Строгий, Без стекла, OLED (чёрный фон), Бумага (тёплый светлый). Стиль только заполняет пункты — дальше их можно править.

## Экспорт, импорт, синхронизация
- «Экспорт» копирует тему как JSON (`{"meowave":"theme","v":1,"a":{…},"d":{…},"l":{…}}`), «Импорт» принимает такой JSON: цвета только `#rrggbb`, числа зажаты в допустимые пределы, варианты — из списка; испорченный JSON отклоняется целиком.
- Тема уходит в аккаунт (`profiles.prefs.cz`, до 3000 символов) и приезжает на другое устройство, если там своей темы ещё нет.

## Как устроено
- `src/custom.js` — схема разделов, редактор, генерация одной таблицы стилей `<style id="cz-style">` (правила с `!important`, цвета под `html[data-theme="dark|light"]`).
- Хранится только то, что отличается от стандарта (`S.x.cz`: `a` — общее, `d`/`l` — цвета тем); сброс — удаление ключа.
- `boot.js` вставляет последнюю таблицу (`localStorage.meowave_cz_css`) до первого кадра — свой фон не мигает стандартным.
- Хуки в `app.js`: `window.CZ_FIELD` (цвет частиц), `window.CZ_FLAT` (полоса прогресса без волны), `czAdopt(prefs.cz)` при загрузке профиля.
- Масштаб: `getCurrentWebview().setZoom()` (разрешение `core:webview:allow-set-webview-zoom`); в мини-плеере масштаб всегда 1.
- Поиск «Найти элемент…» фильтрует по названию раздела и пунктов; поиск настроек открывает раздел с совпадением.
