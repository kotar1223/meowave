# Иконка приложения

Запрос: «скругли иконку Meowave на рабочем столе и таскбаре».
- Иконка — сквиркл (суперэллипс, n = 5, как плитки Windows 11 и iOS) с прозрачным отступом 3,5 %.
- Перегенерированы все файлы: `src-tauri/icons/*.png`, `icon.ico` (16, 20, 24, 32, 40, 48, 64, 128, 256), `icon.icns`, а также `src/icons/icon.png` (заголовок окна, заставка, боковое меню).
- Скрипт: `python scripts/round-icons.py` (нужны `pillow` и `numpy`). Исходник — квадратный оригинал `scripts/assets/icon-square.png`. Запускать только с него: повторный прогон по уже скруглённой иконке уменьшит рисунок.
- В `npm run dev` новая иконка видна у окна и в панели задач. Ярлык на рабочем столе обновится после сборки и установки (`npm run build`). Если Windows показывает старую иконку, это её кэш: `ie4uinit.exe -show` или перезапуск Проводника.
