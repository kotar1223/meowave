# Скачивание и офлайн

Запрос (раунды 8 и 9): «скачанные треки должны играть в офлайне без добавления локальных файлов».

## Скачивание
- «Скачать» в меню трека, кнопка у плейлиста, «Скачивать избранное» / «Скачивать в плейлисты» (Настройки → Фонотека). Файл идёт через тот же прокси, что и воспроизведение (`download_track` в `local.rs`); YouTube перекодируется в mp3, если есть ffmpeg.
- «С эквалайзером и скоростью» (`download_processed`) запекает звук в файл — это другой звук, поэтому такой файл **не** подменяет трек при воспроизведении.
- Spotify — только каталог: скачивание берёт звук там, где его находит воспроизведение (`dlSource()` → `sprResolve()`), а запоминает файл под треком Spotify. Раньше прокси отвечал «unknown service: sp».

## Скачанное играет с диска (раунд 9)
- После скачивания `offRemember()` регистрирует файл в Rust (`local_offline`) и запоминает `"сервис:id" → путь` плюс название, артиста, обложку — в `localStorage` под ключом `mw.offline` (до 4000 записей, отдельно от основного состояния: пути у каждой машины свои, в облако не уходят).
- `streamUrl()` первым делом спрашивает `offId(tr)`: если файл подтверждён, трек играет по маршруту `/stream/local/<id>` — сразу, без трафика и без сети. У трека Spotify, уже подобранного на другом сервисе, проверяется и ключ `sp:<id>` (`_spOrig`); скачанный трек Spotify вообще не ищется по сервисам.
- При запуске `offBoot()` отдаёт все пути в `local_offline` (async, на пуле потоков: отключённый диск или спящая сетевая папка не замораживают окно). Подтверждённые — играют с диска; не найденные — играют из сети; не найденные два месяца — забываются.
- Файл не открылся (удалён, перемещён, битый) — `offFailed()` помечает его на эту сессию, снекбар «Скачанный файл не открылся — играем из сети», трек перезапускается с сервиса с той же секунды.
- Без сети (`navigator.onLine === false`): `next()` пропускает то, что не скачано; трек без файла не ищется по сервисам — «Нет сети — пропускаем то, что не скачано» и переход к скачанному.
- Выбор «Другой источник» — явное желание слушать с сервиса: копия помечается `_net`, файл её не подменяет.
- Следующий трек, если он скачан, не запрашивается заранее (`prefetchNextSoon`).

## Где видно
- «Медиа → Мои файлы»: под локальными файлами блок «Скачанные» (новые сверху, «Играть всё», «Найти скачанные»), очередь из него — контекст `dl`.
- В строках трека рядом с сервисом — значок `download_done` («Скачан — играет с диска»).
- В меню трека — «Не играть с диска» (забывает связь, файл остаётся).
- Настройки → Фонотека: «Играть скачанное с диска» (`S.dlPlay`, включено) и «Найти скачанные раньше».

## Скачанные до раунда 9
`offFind()` просматривает папку загрузок (`local_scan_bg`, глубина 2) и связывает файл с треком библиотеки только при **точном** совпадении имени, которое Meowave даёт загрузке: `Артист - Название` с той же заменой символов, что в `download_track`, и необязательным « (2)». Ремикс с похожим названием к оригиналу не привяжется. Один раз запускается сам (через 9 с после старта, для каждой папки загрузок), дальше — кнопкой.
