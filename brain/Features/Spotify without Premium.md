# Spotify без Premium

Запрос: «надо придумать что-то новое для стриминга со Spotify без подписки».

## Как работает
1. Spotify служит каталогом: поиск, библиотека и плейлисты через официальный вход (PKCE).
2. Звук для трека Spotify берётся из другого сервиса. `sprResolve()` ищет по нескольким запросам (очищенное название, альтернативный вариант, «исполнитель название audio», только название) в YouTube Music, Яндекс Музыке и SoundCloud.
3. `sprScore()` оценивает кандидатов: сходство названия (вес 60) и исполнителя (вес 35), близость длительности, штраф за другие версии (live, remix, sped up, slowed, nightcore, cover, karaoke, instrumental и т. п.), небольшой бонус источнику (YTM +6, Яндекс +5, SoundCloud −2).
4. Лучшее совпадение кэшируется (`sprMap()`, ключ `sp:<id>`). Следующие два трека очереди подбираются заранее, через 4 с после старта (`sprPrefetchNext()`).
5. На острове полноэкранного плеера можно выбрать другой источник (`spSourcePicker()`); выбор запоминается.

DRM Spotify не обходится: звук идёт из бесплатных источников, которые Meowave уже поддерживает.

## Раунд 3
- Треки Spotify играют и **без входа** в Spotify: звук всё равно берётся по строгому подбору с других сервисов.
- Страница артиста Spotify без входа — см. [[Features/Collections and artists]].
