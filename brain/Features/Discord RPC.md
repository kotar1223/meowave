# Discord RPC

- **Причина поломки** (раунд 1): ID приложения брался только из переменной окружения, которую пользователи не задают.
- **Сейчас**: Application ID вводится в «Настройки → Сеть → Discord», кнопки «Сохранить» и «Проверить» (показывает настоящий ответ Discord). Статус в профиле — «Слушает …», на паузе таймер останавливается, в настройках есть точка статуса и превью карточки.
- **Настройка**: на https://discord.com/developers/applications создай приложение с названием «Meowave» (это имя Discord покажет в «Слушает …»), скопируй Application ID в настройки, нажми «Сохранить», затем «Проверить».
- Код: `src-tauri/src/discord.rs` (IPC), интерфейс в `src/app.js`.
