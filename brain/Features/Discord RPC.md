# Discord RPC

- **Причина поломки** (раунд 1): ID приложения брался только из переменной окружения, которую пользователи не задают.
- **Раунд 1–6**: Application ID вводился в «Настройки → Сеть → Discord», кнопки «Сохранить» и «Проверить». Статус в профиле — «Слушает …», на паузе таймер останавливается.
- **Раунд 7 — без ввода ID**: Discord не принимает статус без приложения, но его ID публичный, поэтому он встроен в сборку. Порядок: свой ID из «Для разработчиков» → `DISCORD_CLIENT_ID` в окружении → `DISCORD_CLIENT_ID` при сборке (секрет репозитория, `release.yml`) → константа `MEOWAVE_APP_ID` в `discord.rs`.
- **Что сделать владельцу один раз**: создать на https://discord.com/developers/applications приложение «Meowave» (это имя Discord покажет в «Слушает …»; обложка трека и знак сервиса идут ссылками, картинки загружать не нужно), ID положить в секрет `DISCORD_CLIENT_ID` или в `MEOWAVE_APP_ID`. Пока ID нет, настройки пишут: «В этой сборке нет встроенного приложения Discord».
- **Настройки раунда 7**: один переключатель «Показывать в Discord, что я слушаю», точка статуса («Discord найден» / «не запущен»), живое превью карточки, понятные ошибки (Discord закрыл соединение, не принял ID, не отвечает). Свой ID — в свёрнутом блоке «Для разработчиков».
- Код: `src-tauri/src/discord.rs` (IPC), интерфейс в `src/app.js`.

## Раунд 8
- Встроен ID приложения владельца `1567590469779726407` (`MEOWAVE_APP_ID`); переменная `DISCORD_CLIENT_ID` при запуске или сборке его заменяет. Тест проверяет, что без переменной берётся встроенный ID.
