# Известные проблемы и ограничения

- **Rust не собирается в песочнице агента** (нет toolchain). Rust-код в раунде 2 не менялся, в раунде 1 менялся `discord.rs`. Если `npm run dev` падает на Rust, пришли текст ошибки.
- **Discord RPC** работает только с Application ID: создай приложение на https://discord.com/developers/applications.
- **«Переходы» — не настоящий кроссфейд**: конец трека затухает, следующий нарастает, но треки не звучат одновременно.
- **Поиск в настройках** ищет только по разделам настроек. Реверб и эквалайзер живут в EQ-доке, настройки фона и текста — в шторке полноэкранного плеера.
- **На телефоне (≤700 px)** панель инструментов текста (смещение, Genius, тайминги) в полноэкранном плеере скрыта ради места.
- **Spotify без Premium** может выбрать не ту версию трека (live, ремикс). Есть кнопка «выбрать другой источник», выбор запоминается.
- **Иконка на ярлыке** обновится только после установки новой сборки. Если Windows показывает старую, это кэш иконок: `ie4uinit.exe -show` или перезапуск Проводника.
- В `icon.icns` нет записей 16×16 и 32×32 @1x (Pillow их не пишет); macOS берёт @2x, на Windows не влияет.
- **Свечение** при первом запуске беты один раз сброшено в «выкл» (новая палитра). Включить можно в настройках плеера.
- **Тесты статические**: они разбирают HTML/CSS/JS, а не кликают реальный интерфейс. Визуальная проверка — скриншотами в headless Chromium.
- **Оптимизация не полная**: ускорены фон, волна и CSS, но полного профилирования всего приложения (поиск, чаты, библиотека) ещё не было.
- В `app.js` остались мёртвые ветки старого плеера (`#fpbody`, `.fpseek`); они безвредны, их можно удалить при разбиении на модули.
- В `app.css` остались неиспользуемые стили `quasar-*` (возможно, понадобятся экрану Quasar).
